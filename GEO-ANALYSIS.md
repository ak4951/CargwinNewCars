# GEO-анализ: готовность hunter.lease к ИИ-поиску

**Объект:** боевой сайт `https://hunter.lease/`; отдельным разделом — код этого репозитория
**Дата:** 2026-09-15
**Метод:** HTTP-запросы к боевому домену из обычной сети (curl, семь разных User-Agent),
обход всех 202 URL из обоих sitemap, сверка с кодом ветки `claude/skill-upload-setup-bet888`

## Что изменилось по сравнению с версией от 2026-09-14

Прошлая версия поставила сайту **14 из 100**. Вся оценка держалась на выводе из кода сборки:
сайт отдаётся пустой SPA-оболочкой, и ИИ-краулеры не видят ни текста, ни микроразметки.
Живой сайт тогда проверить не удалось, песочница блокировала hunter.lease.

Проверка по факту: **вывод неверен, и оценка 14/100 тоже.**

1. hunter.lease отдаёт полностью отрендеренный HTML (текст, заголовки, JSON-LD) **любому**
   клиенту. HTML главной для браузерного UA, curl, Googlebot, GPTBot, OAI-SearchBot, ClaudeBot
   и PerplexityBot одинаков до байта: один md5, 152 359 байт. Это не отдача HTML ботам по
   User-Agent и не клоакинг, а пререндер и серверный рендер для всех.
2. **Боевой сайт собирается не из этого репозитория.** Статический анализ `frontend/` в прошлой
   версии описывал код, который на hunter.lease не работает. Доказательства — в разделе
   «Этот репозиторий».

Дальше — оценка по тому, что сервер отдаёт на самом деле.

## Как проверялось

```bash
curl -sL https://hunter.lease/ | head -100
curl -sL -A "Mozilla/5.0 AppleWebKit/537.36 (KHTML, like Gecko); compatible; GPTBot/1.2; +https://openai.com/gptbot" https://hunter.lease/ | md5sum
curl -sL https://hunter.lease/robots.txt
curl -sL https://hunter.lease/sitemap.xml
curl -sL https://hunter.lease/llms.txt
```

Для каждого URL из `/sitemap.xml` (169) и `/sitemap-featured.xml` (33) проверялись код ответа,
текст в `#root`, число блоков `application/ld+json`, `<title>`, `rel="canonical"`, `noindex`,
число H1, автор и `dateModified` в JSON-LD.

Ограничение: запросы с подменённым User-Agent шли не с IP-адресов самих ботов. Если Cloudflare
обрабатывает верифицированных ботов отдельно (AI Crawl Control, Bot Fight Mode), отсюда этого не
видно. Проверять в логах Cloudflare.

## Оценка: ≈ 71 / 100

Шкала та же, что в прошлой версии (скил `seo-geo`), но теперь по фактической выдаче. Баллы по
критериям — экспертная оценка по данным ниже, а не результат формулы.

| Критерий | Вес | Балл | Почему |
|---|---|---|---|
| Цитируемость пассажей | 25% | 70 | медиана 1 212 слов серверного текста, проверяемые факты; но каталог `/deals` не отдаёт краулеру ни одного оффера |
| Структурная читаемость | 20% | 75 | ровно один H1 на каждой из 202 страниц, FAQPage на 124; таблицы только на 3 |
| Мультимодальность | 15% | 50 | alt у всех картинок в выборке, свой og:image; в гайдах нет изображений, нет видео, калькулятор не отрендерен |
| Авторитет и бренд | 20% | 70 | автор-основатель с лицензией на 131 странице; у 136 страниц нет `dateModified`, рейтинг на Organization самоподтверждающий |
| Техническая доступность | 20% | 85 | пререндер для всех, 202 из 202 URL чистые, ИИ-краулеры разрешены, есть llms.txt; дыра в пер-ботовых группах robots.txt |

## 2. Доступ ИИ-краулеров

Живой `/robots.txt`: группа `*` с `Allow: /`, `Disallow: /go/`, `Disallow: /api/` (кроме
прокси картинок) и `Content-Signal: search=yes,ai-input=yes,ai-train=yes`.

Поиск и цитирование:

| Бот | За что отвечает | Статус |
|---|---|---|
| Googlebot | Google Search, AI Overviews, AI Mode | разрешён через группу `*` |
| OAI-SearchBot | цитируемость в ChatGPT Search | разрешён, своя группа |
| Claude-SearchBot | цитируемость в поиске Claude | разрешён, своя группа |
| PerplexityBot | поиск Perplexity | разрешён, своя группа |
| Bingbot | Bing и Copilot | разрешён через группу `*` |
| Applebot | Siri, Spotlight, Safari | разрешён через группу `*` |

Обучение моделей:

| Бот | За что отвечает | Статус |
|---|---|---|
| GPTBot | обучение моделей OpenAI | разрешён, своя группа |
| ClaudeBot | обучение моделей Anthropic | разрешён, своя группа |
| Google-Extended | обучение и гроундинг Gemini/Vertex, **не** выдача Google | разрешён, своя группа |
| Applebot-Extended | обучение Apple Intelligence | разрешён, своя группа |
| CCBot | Common Crawl | разрешён, своя группа |

ChatGPT-User и Perplexity-User ходят по запросу пользователя и robots.txt не соблюдают по
определению; группы для них есть.

**Реальная дыра — та же, что была в этом репозитории.** В каждой пер-ботовой группе только
`Allow: /`. Бот со своей группой игнорирует группу `*` целиком (RFC 9309), поэтому
`Disallow: /go/` и `Disallow: /api/` **не действуют** на OAI-SearchBot, ChatGPT-User,
PerplexityBot, Perplexity-User, ClaudeBot, Claude-SearchBot, GPTBot, GoogleOther и CCBot. Им
разрешено ходить по JSON-эндпоинтам и трекинговым редиректам — ровно туда, куда комментарий в
файле пускать их не хочет. Для Google-Extended и Applebot-Extended это неважно: сами они не
краулят, это только метки.

Исправление: повторить общие правила в каждой группе или собрать ботов в одну группу:

```
User-agent: OAI-SearchBot
User-agent: ChatGPT-User
User-agent: PerplexityBot
User-agent: Perplexity-User
User-agent: ClaudeBot
User-agent: Claude-SearchBot
User-agent: GPTBot
User-agent: GoogleOther
User-agent: CCBot
User-agent: Google-Extended
User-agent: Applebot-Extended
Allow: /
Disallow: /go/
Disallow: /api/
Allow: /api/inventory/photo/
Allow: /api/car-photos/
```

## 3. llms.txt и sitemap

- `/llms.txt` есть: 32,7 КБ, обновлён 2026-09-14. Ключевые факты (лицензия #21138, сбор $95,
  требование SSN, отмена федерального EV-кредита), разделы со ссылками на гайды и модельные
  страницы. Оформлен образцово. Google прямо пишет, что `llms.txt` на выдачу Google не влияет;
  другим ИИ-системам он может пригодиться, но рычагом ранжирования его считать не стоит.
- `/llms-full.txt` отвечает 404. Он не обязателен.
- `/sitemap.xml` — 169 URL, `/sitemap-featured.xml` — 33 индексируемых оффера, оба объявлены в
  robots.txt. Около тысячи быстро меняющихся офферов закрыты `noindex` намеренно (так сказано в
  комментарии robots.txt), и это разумно.

## 4. Микроразметка

В исходном HTML, без JavaScript: WebSite, Organization, Person (основатель, лицензия оформлена
как EducationalOccupationalCredential), AboutPage, FAQPage (124 страницы), HowTo, Article-типы
(61 страница), Car + Offer + UnitPriceSpecification на карточках, ItemList.

Что поправить:

- **AggregateRating 4.6 / 87 на Organization** (`itemReviewed: #org`) на главной и
  `/how-it-works`. Отзывы видны на странице, это хорошо. Но видно их 11, а заявлено 87. Если
  остальные собраны с внешних площадок (Google, Yelp), их агрегирование в своей разметке
  противоречит правилам Google для отзывов. Кроме того, для самоподтверждающих отзывов
  Organization и LocalBusiness Google звёзды не показывает, так что rich-результата не будет в
  любом случае. Нужно проверить, откуда число 87, и либо привязать рейтинг к показанным
  отзывам, либо убрать AggregateRating.
- ItemList на `/deals` пустой: разметка обещает список, которого в HTML нет.
- Часть отзывов подписана «Hunter Lease client». Анонимный автор ослабляет доверие к отзыву.

## 5. Цитируемость и структура

Сильные стороны:

- медиана 1 212 слов серверного текста на SPA-страницу (от 191 на карточке оффера до 6 280 на
  `/terms`);
- ровно один H1 на каждой из 202 страниц, FAQ-блоки на 124;
- конкретные проверяемые факты: номер лицензии, фиксированный сбор $95, дата отмены
  EV-кредита, собственное исследование 411 сделок (`/lease-transparency-study`), определения в
  гайдах («Money factor: the lease rate, and where markup hides»).

Слабые стороны:

- **Каталог `/deals` не отдаёт краулеру ни одного оффера.** Для ИИ главная коммерческая
  страница выглядит как вводный текст без цен. Офферы видны только на `/deal/…` (33 в sitemap),
  `/under-*` и `/best-california-lease-deals`.
- Таблицы есть только на 3 страницах из 202. Сравнения моделей, ставки, «лизинг против
  кредита» — готовый табличный материал, а ИИ-ответы охотно цитируют таблицы.
- H1 «Buy on your terms» одинаковый у `/` и `/how-it-works`; H1 на `/about` — безликое
  «About Us».

Пассажный разбор (блоки по 134–167 слов) не делался, см. «Чего в этом отчёте нет».

## 6. Авторитет и свежесть

- Автор-человек с регалиями (`Azat Cutliahmetov, Founder, licensed California auto broker
  #21138`) и `sameAs` указан на 131 странице.
- `dateModified` есть только у 66 URL из 202: 26 за июнь 2026, 29 за июль, 2 за август, 9 за
  сентябрь. У 136 страниц даты нет вовсе.
- Самые старые даты — 2026-06-01 (сравнения моделей Hyundai), это 3,5 месяца. По данным
  SE Ranking, страницы моложе трёх месяцев цитируются примерно втрое чаще, а после полугода без
  обновления теряют шансы. График обновления — один из самых дешёвых рычагов.

## 7. Мультимодальность

- У всех изображений в выборке есть `alt`, у каждой страницы свой `og:image`.
- В гайдах изображений нет: на `/money-factor`, `/best-california-lease-deals` и `/about` ни
  одного.
- Видео не встроено, хотя у основателя около 950 тыс. подписчиков с разборами сделок (TikTok,
  Instagram, YouTube). Встроенный YouTube-разбор на модельной странице дал бы и мультимодальный
  сигнал, и связь сущностей.
- Калькулятор `/calculator` — уникальный инструмент, но краулер видит пустую страницу (п. 1).

## Этот репозиторий (CargwinNewCars)

**hunter.lease собирается не отсюда.** Всё перечисленное видно снаружи:

- Живой `robots.txt` совсем другой: `Content-Signal`, `Disallow: /go/`, `Allow: /api/car-photos/`,
  группы `OAI-SearchBot` и `Claude-SearchBot`. В `frontend/public/robots.txt` этого репозитория
  ничего такого не было, зато была группа `Claude-Web`, которой на сайте нет.
- Sitemap, объявленные здесь (`/sitemap-seo-pages.xml`, `/sitemap-articles.xml`), и
  `/api/sitemap.xml` из `backend/server.py` на боевом домене отвечают 404.
- Маршруты этого репозитория `/offers` и `/car/:carId` на боевом домене отвечают 404.
- Боевые скрипты называются `/assets/index-<hash>.js` (так именует Vite), а `react-scripts
  build` этого репозитория даёт `/static/js/main.<hash>.js`.
- На сайте лежит `/llms.txt` на 32 КБ, в этом репозитории его нет.

Поэтому выводы прошлой версии о коде верны **для этого кода** и важны, только если его
когда-нибудь выкатят:

| Находка | Статус |
|---|---|
| Нет пререндера, контент и JSON-LD только на клиенте | в силе |
| `backend/ai_schema_generator.py` нигде не импортируется | в силе. Внутри тоже захардкожены рейтинги 4.9/847 и 4.8/127, выкатывать модуль как есть нельзя |
| `aggregateRating` 4.9/847 в `frontend/src/App.js` | **исправлено**: удалён |
| `og:url` и `twitter:url` указывают на `cargwin-newcar.emergent.host` | **исправлено**: `https://hunter.lease/` |
| Нет `rel="canonical"` | **исправлено**: canonical на каждый маршрут через `react-helmet-async` (`frontend/src/components/CanonicalLink.jsx`); дубли склеены: `/offers` → `/deals`, `/cars/:id` и `/offer/:id` → `/car/:id`. В `index.html` статический canonical сознательно не добавлен: этот файл отдаётся на любой URL, и статический тег объявил бы каждую страницу дублем главной |
| robots.txt: `Claude-Web`, нет `OAI-SearchBot` и `Claude-SearchBot`, в группах ботов нет `Disallow` | **исправлено** |
| robots.txt объявляет sitemap, которых нет | в силе |
| GA-идентификатор — плейсхолдер `G-XXXXXXXXXX` | в силе |
| Бейдж «Made with Emergent» в `index.html` | в силе |
| Маршрут `/offer/:id` рендерит `CarDetail`, а тот читает параметр `carId`; на этом URL он всегда `undefined` | новая находка, в силе |
